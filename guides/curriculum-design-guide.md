# 🗺️ Curriculum Designer Guide

A step-by-step manual to create ADA-aligned microcourses and learning atoms.

---

## 1. Define the Competency
Choose a real-world skill the learner must develop and why it matters.

## 2. Map Learning Objectives
Use Bloom's taxonomy to write objectives for **remember**, **understand**, and **apply** levels.

### Bloom's Taxonomy Quick Guide
Each learning objective starts with an action verb that signals the expected cognitive skill. Select verbs that align with the desired level using the table below:

| Level       | Sample Verbs               |
| ----------- | ------------------------- |
| Remember    | list, define, recall      |
| Understand  | explain, summarize, describe |
| Apply       | use, implement, demonstrate |
| Analyze     | differentiate, compare, organize |
| Evaluate    | critique, justify, assess |
| Create      | design, construct, formulate |

**Example:**
*Remember*: "List the primary colors."  
*Understand*: "Explain how complementary colors interact."  
*Apply*: "Create a color wheel demonstrating complementary pairs."

## 3. Design Learning Atoms
For each objective, assemble a combination of atoms:
- **Read** – texts or infographics
- **Listen** – podcasts or narrations
- **Watch** – videos or demos
- **Practice** – hands-on tasks or labs
- **Evaluate** – quizzes, rubrics, or AI prompts
- **Collaborate** – peer or mentor interaction

Start from the [Learning Atom Template](../templates/learning-atom-template.md).

## 4. Assemble Modules
Group related atoms into modules with clear themes and a lab or challenge.

## 5. Plan Assessment
Decide how learners will be evaluated: automated checks, rubrics, or peer review.

## 6. Specify Deliverables
Describe tangible outputs such as reports, prototypes, or reflections.

## 7. Include Human Interaction
Schedule mentoring sessions, forums, or live workshops to foster community.

Use the [Microcourse Template](../templates/microcourse-ada-template.md) as a starting point and adapt it to your domain.
