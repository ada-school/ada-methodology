# 🗺️ ADA Curriculum Designer Guide

### Step-by-Step Manual for Designing ADA-Aligned Microcourses and Learning Atoms

This guide provides a **practical workflow** for instructors, mentors, and course designers to create **job-ready micro-credentials** using the **Applied Digital Apprenticeship (ADA) methodology**.

---

## 1. Define the Competency

Identify a **real-world job competency** that the learner must develop. Connect it to recognized frameworks when possible:

* [SFIA – Skills Framework for the Information Age.](https://sfia-online.org/en/framework)

* [O\*NET Online – Occupational Information Network (US).](https://www.onetonline.org/)

* [ESCO – European Skills, Competences, Qualifications and Occupations.](https://esco.ec.europa.eu/en)

* [ILO – International Labour Organization Skills and Employability.](https://www.ilo.org/skills/lang--en/index.htm)


---

## 2. Map Learning Objectives

Write **Bloom’s taxonomy-aligned objectives** that scaffold from lower-order (remember, understand) to higher-order (analyze, evaluate, create). Each objective should be measurable.

### Bloom’s Taxonomy Quick Reference

| Level      | Sample Verbs                     |
| ---------- | -------------------------------- |
| Remember   | list, define, recall             |
| Understand | explain, summarize, describe     |
| Apply      | use, implement, demonstrate      |
| Analyze    | differentiate, compare, organize |
| Evaluate   | critique, justify, assess        |
| Create     | design, construct, formulate     |

**Example:**

* **Remember**: "List the primary colors."
* **Understand**: "Explain how complementary colors interact."
* **Apply**: "Create a color wheel demonstrating complementary pairs."
* **Analyze**: "Compare traditional vs. digital color models."
* **Evaluate**: "Assess the effectiveness of a brand’s color palette."
* **Create**: "Design a color scheme for a new product launch."

---

## 3. Design Learning Atoms ⚛

Each **learning atom** focuses on a single learning objective and integrates **Concept → Example → Practice → Evaluation**.

### Atom Components

* **Read** – Articles, guides, infographics, case studies.
* **Listen** – Podcasts, expert interviews, narrated content.
* **Watch** – Videos, animations, demos, simulations.
* **Practice** – Labs, coding challenges, design tasks.
* **Evaluate** – Quizzes, rubrics, AI-driven checks.
* **Collaborate** – Peer feedback, discussions, mentor check-ins.

👉 Use the [Learning Atom Template](../templates/learning-atom-template.md) to design each atom.

---

## 4. Assemble Modules (Microcourse Structure)

Group **4–8 learning atoms** into modules with a clear theme. Each module should:

* Introduce a **theoretical foundation**.
* Include a **lab or applied challenge**.
* End with an **evaluation or reflection**.

👉 Use the [Microcourse Template](../templates/micro-credential-ada-template.md) for structuring.

---

## 5. Plan Assessment Strategy

Assessments should combine **formative (ongoing)** and **summative (final)** methods.

* **Labs & Atoms** → Mini-Rubric (3 criteria: Accuracy, Application, Clarity).
* **Capstone Project** → Standard Rubric (5 criteria: Relevance, Application, Problem-Solving & Creativity, Clarity & Communication, Collaboration & Reflection).

---

## 6. Define Deliverables

Clearly describe what learners will produce and how it demonstrates the competency.

* Examples: *Code repository, business plan, design prototype, research report, video pitch.*
* Deliverables must be **portfolio-ready** and **job-relevant**.

---

## 7. Human & Collaborative Interaction

Integrate opportunities for mentorship, feedback, and community learning.

* 🧑‍🏫 Mentor sessions / office hours
* 👥 Group challenges or peer reviews
* 🌐 Forums or Slack/Discord communities
* 🎤 Project presentations and showcases

---

## 8. Align with ADA Phases

Make sure your course flows through the **4 ADA learning phases**:

1. **🙊 Self-Guided Introduction** → readings, videos, quizzes.
2. **🙉 Visual Exploration** → demos, role-play, walkthroughes.
3. **🙈 Applied Practice** → labs, tools, simulations.
4. **🐵 Collaboration & Reflection** → peer interaction, project sharing.

---

## 9. Example Workflow

1. **Competency**: *Data Visualization with Python*.
2. **Objectives**: *Understand charts → Apply libraries → Create dashboard.*
3. **Atoms**: *Intro to matplotlib, Case study, Lab on bar charts.*
4. **Module**: *Data Visualization Basics.*
5. **Assessment**: *Mini-rubric for labs, capstone dashboard with rubric.*
6. **Deliverable**: *Interactive dashboard shared on GitHub.*
7. **Human Interaction**: *Peer feedback on dashboard design.*
8. **Phases**: *Concept (Self-study) → Demo (Visual) → Lab (Practice) → Peer Showcase (Collaboration).*

---

## ✅ Checklist for Designers

Use this checklist to ensure your micro-credential is ADA-aligned. Examples are included in italics for clarity.

* [ ] **Defined a real-world competency**
  *Example: "Ability to design a customer journey map for digital marketing."*
* [ ] **Linked to frameworks/standards (SFIA, O\*NET, ESCO, ILO)**
  *Example: "ESCO: Marketing Specialist – Customer Journey Design."*
* [ ] **Wrote Bloom-aligned learning objectives**
  *Example: "Analyze user behavior using funnel metrics."*
* [ ] **Designed 4–8 learning atoms**
  *Example: Atoms on customer personas, analytics dashboards, A/B testing.*
* [ ] **Assembled atoms into modules**
  *Example: Module = "User Analytics Basics" with 3 atoms + a lab.*
* [ ] **Defined assessments with rubrics**
  *Example: Mini-rubric for analytics lab; capstone rubric for final marketing strategy.*
* [ ] **Specified deliverables (portfolio-ready)**
  *Example: A customer journey map PDF and a data-driven marketing report.*
* [ ] **Planned human/collaborative elements**
  *Example: Weekly mentor Q\&A and peer review of reports.*
* [ ] **Mapped phases (Hear → See → Do → Share)**
  *Example: Self-study readings → Demo videos → Analytics lab → Peer showcase.*
