# 🗺️ Guia do Designer de Currículo ADA

### Manual Passo a Passo para Projetar Microcursos e Átomos de Aprendizado Alinhados com ADA

Este guia fornece um **fluxo de trabalho prático** para instrutores, mentores e designers de curso para criar **micro-credenciais prontas para o trabalho** usando a **metodologia de Aprendizado Digital Aplicado (ADA)**.

---

## 1. Definir a Competência

Identifique uma **competência profissional do mundo real** que o aprendiz deve desenvolver. Conecte-a com frameworks reconhecidos quando possível:

* [SFIA – Framework de Habilidades para a Era da Informação.](https://sfia-online.org/en/framework)

* [O\*NET Online – Rede de Informação Ocupacional (EUA).](https://www.onetonline.org/)

* [ESCO – Habilidades, Competências, Qualificações e Ocupações Europeias.](https://esco.ec.europa.eu/en)

* [OIT – Organização Internacional do Trabalho Habilidades e Empregabilidade.](https://www.ilo.org/skills/lang--en/index.htm)

---

## 2. Mapear Objetivos de Aprendizado

Escreva **objetivos alinhados com a taxonomia de Bloom** que progridam de ordem inferior (lembrar, compreender) para ordem superior (analisar, avaliar, criar). Cada objetivo deve ser mensurável.

### Referência Rápida da Taxonomia de Bloom

| Nível      | Verbos de Exemplo                           |
| ---------- | ------------------------------------------- |
| Lembrar    | listar, definir, recordar                  |
| Compreender| explicar, resumir, descrever               |
| Aplicar    | usar, implementar, demonstrar              |
| Analisar   | diferenciar, comparar, organizar           |
| Avaliar    | criticar, justificar, avaliar              |
| Criar      | projetar, construir, formular              |

**Exemplo:**

* **Lembrar**: "Listar as cores primárias."
* **Compreender**: "Explicar como as cores complementares interagem."
* **Aplicar**: "Criar um círculo cromático demonstrando pares complementares."
* **Analisar**: "Comparar modelos de cor tradicionais vs. digitais."
* **Avaliar**: "Avaliar a eficácia da paleta de cores de uma marca."
* **Criar**: "Projetar um esquema de cores para o lançamento de um novo produto."

---

## 3. Projetar Átomos de Aprendizado ⚛

Cada **átomo de aprendizado** foca em um único objetivo de aprendizado e integra **Conceito → Exemplo → Prática → Avaliação**.

### Componentes do Átomo

* **Ler** – Artigos, guias, infográficos, estudos de caso.
* **Escutar** – Podcasts, entrevistas de especialistas, conteúdo narrado.
* **Assistir** – Vídeos, animações, demonstrações, simulações.
* **Praticar** – Laboratórios, desafios de código, tarefas de design.
* **Avaliar** – Questionários, rubricas, verificações com IA.
* **Colaborar** – Feedback entre pares, discussões, check-ins com mentores.

👉 Use o [Modelo de Átomo de Aprendizado](../templates/learning-atom-template.md) para projetar cada átomo.

---

## 4. Montar Módulos (Estrutura de Microcurso)

Agrupe **4–8 átomos de aprendizado** em módulos com um tema claro. Cada módulo deve:

* Introduzir uma **base teórica**.
* Incluir um **laboratório ou desafio aplicado**.
* Terminar com uma **avaliação ou reflexão**.

👉 Use o [Modelo de Microcurso](../templates/micro-credential-ada-template.md) para estruturar.

---

## 5. Planejar Estratégia de Avaliação

As avaliações devem combinar métodos **formativos (contínuos)** e **somativos (finais)**.

* **Laboratórios e Átomos** → Mini-Rubrica (3 critérios: Precisão, Aplicação, Clareza).
* **Projeto Capstone** → Rubrica Padrão (5 critérios: Relevância, Aplicação, Resolução de Problemas e Criatividade, Clareza e Comunicação, Colaboração e Reflexão).

---

## 6. Definir Entregáveis

Descreva claramente o que os aprendizes produzirão e como isso demonstra a competência.

* Exemplos: *Repositório de código, plano de negócios, protótipo de design, relatório de pesquisa, pitch em vídeo.*
* Os entregáveis devem estar **prontos para portfólio** e ser **relevantes para o trabalho**.

---

## 7. Interação Humana e Colaborativa

Integre oportunidades para mentoria, feedback e aprendizado comunitário.

* 🧑‍🏫 Sessões de mentor / horário de atendimento
* 👥 Desafios em grupo ou revisões entre pares
* 🌐 Fóruns ou comunidades Slack/Discord
* 🎤 Apresentações de projetos e showcases

---

## 8. Alinhar com as Fases ADA

Certifique-se de que seu curso flua através das **4 fases de aprendizado ADA**:

1. **🙊 Introdução Autoguiada** → leituras, vídeos, questionários.
2. **🙉 Exploração Visual** → demonstrações, interpretação, percursos.
3. **🙈 Prática Aplicada** → laboratórios, ferramentas, simulações.
4. **🐵 Colaboração e Reflexão** → interação entre pares, compartilhamento de projetos.

---

## 9. Exemplo de Fluxo de Trabalho

1. **Competência**: *Visualização de Dados com Python*.
2. **Objetivos**: *Compreender gráficos → Aplicar bibliotecas → Criar dashboard.*
3. **Átomos**: *Introdução ao matplotlib, Estudo de caso, Laboratório sobre gráficos de barras.*
4. **Módulo**: *Fundamentos de Visualização de Dados.*
5. **Avaliação**: *Mini-rubrica para laboratórios, dashboard capstone com rubrica.*
6. **Entregável**: *Dashboard interativo compartilhado no GitHub.*
7. **Interação Humana**: *Feedback entre pares sobre design do dashboard.*
8. **Fases**: *Conceito (Autoestudo) → Demo (Visual) → Laboratório (Prática) → Showcase entre Pares (Colaboração).*

## ✅ Lista de Verificação para Designers

Use esta lista de verificação para garantir que sua micro-credencial esteja alinhada com ADA. Exemplos são incluídos em itálico para clareza.

* [ ] **Definiu uma competência do mundo real**
  *Exemplo: "Capacidade de projetar um mapa de jornada do cliente para marketing digital."*
* [ ] **Vinculado a frameworks/padrões (SFIA, O\*NET, ESCO, OIT)**
  *Exemplo: "ESCO: Especialista em Marketing – Design de Jornada do Cliente."*
* [ ] **Escreveu objetivos de aprendizado alinhados com Bloom**
  *Exemplo: "Analisar comportamento do usuário usando métricas de funil."*
* [ ] **Projetou 4–8 átomos de aprendizado**
  *Exemplo: Átomos sobre personas de clientes, dashboards de analytics, testes A/B.*
* [ ] **Montou átomos em módulos**
  *Exemplo: Módulo = "Fundamentos de Analytics do Usuário" com 3 átomos + um laboratório.*
* [ ] **Definiu avaliações com rubricas**
  *Exemplo: Mini-rubrica para laboratório de analytics; rubrica capstone para estratégia de marketing final.*
* [ ] **Especificou entregáveis (prontos para portfólio)**
  *Exemplo: Um PDF de mapa de jornada do cliente e um relatório de marketing baseado em dados.*
* [ ] **Planejou elementos humanos/colaborativos**
  *Exemplo: Q&A semanal com mentor e revisão entre pares de relatórios.*
* [ ] **Mapeou fases (Ouvir → Ver → Fazer → Compartilhar)**
  *Exemplo: Leituras de autoestudo → Vídeos de demonstração → Laboratório de analytics → Showcase entre pares.*
