# 🗺️ Guía del Diseñador de Currículos ADA

### Manual Paso a Paso para Diseñar Microcursos y Átomos de Aprendizaje Alineados con ADA

Esta guía proporciona un **flujo de trabajo práctico** para instructores, mentores y diseñadores de cursos para crear **micro-credenciales listas para el trabajo** usando la **metodología de Aprendizaje Digital Aplicado (ADA)**.

---

## 1. Definir la Competencia

Identifica una **competencia laboral del mundo real** que el estudiante debe desarrollar. Conéctala con marcos reconocidos cuando sea posible:

* [SFIA – Marco de Habilidades para la Era de la Información.](https://sfia-online.org/en/framework)

* [O\*NET Online – Red de Información Ocupacional (EE.UU.).](https://www.onetonline.org/)

* [ESCO – Habilidades, Competencias, Cualificaciones y Ocupaciones Europeas.](https://esco.ec.europa.eu/en)

* [OIT – Organización Internacional del Trabajo Habilidades y Empleabilidad.](https://www.ilo.org/skills/lang--en/index.htm)

---

## 2. Mapear Objetivos de Aprendizaje

Redacta **objetivos alineados con la taxonomía de Bloom** que progresen desde orden inferior (recordar, comprender) hasta orden superior (analizar, evaluar, crear). Cada objetivo debe ser medible.

### Referencia Rápida de la Taxonomía de Bloom

| Nivel      | Verbos de Ejemplo                           |
| ---------- | ------------------------------------------- |
| Recordar   | enumerar, definir, recordar                |
| Comprender | explicar, resumir, describir               |
| Aplicar    | usar, implementar, demostrar               |
| Analizar   | diferenciar, comparar, organizar           |
| Evaluar    | criticar, justificar, evaluar              |
| Crear      | diseñar, construir, formular               |

**Ejemplo:**

* **Recordar**: "Enumerar los colores primarios."
* **Comprender**: "Explicar cómo interactúan los colores complementarios."
* **Aplicar**: "Crear un círculo cromático que demuestre pares complementarios."
* **Analizar**: "Comparar modelos de color tradicionales vs. digitales."
* **Evaluar**: "Evaluar la efectividad de la paleta de colores de una marca."
* **Crear**: "Diseñar un esquema de colores para el lanzamiento de un nuevo producto."

---

## 3. Diseñar Átomos de Aprendizaje ⚛

Cada **átomo de aprendizaje** se enfoca en un único objetivo de aprendizaje e integra **Concepto → Ejemplo → Práctica → Evaluación**.

### Componentes del Átomo

* **Leer** – Artículos, guías, infografías, casos de estudio.
* **Escuchar** – Podcasts, entrevistas de expertos, contenido narrado.
* **Ver** – Videos, animaciones, demostraciones, simulaciones.
* **Practicar** – Laboratorios, desafíos de código, tareas de diseño.
* **Evaluar** – Cuestionarios, rúbricas, verificaciones con IA.
* **Colaborar** – Retroalimentación entre pares, discusiones, revisiones con mentores.

👉 Usa la [Plantilla de Átomo de Aprendizaje](../templates/learning-atom-template.md) para diseñar cada átomo.

---

## 4. Ensamblar Módulos (Estructura de Microcurso)

Agrupa **4–8 átomos de aprendizaje** en módulos con un tema claro. Cada módulo debe:

* Introducir una **base teórica**.
* Incluir un **laboratorio o desafío aplicado**.
* Terminar con una **evaluación o reflexión**.

👉 Usa la [Plantilla de Microcurso](../templates/micro-credential-ada-template.md) para estructurar.

---

## 5. Planificar Estrategia de Evaluación

Las evaluaciones deben combinar métodos **formativos (continuos)** y **sumativos (finales)**.

* **Laboratorios y Átomos** → Mini-Rúbrica (3 criterios: Precisión, Aplicación, Claridad).
* **Proyecto Capstone** → Rúbrica Estándar (5 criterios: Relevancia, Aplicación, Resolución de Problemas y Creatividad, Claridad y Comunicación, Colaboración y Reflexión).

---

## 6. Definir Entregables

Describe claramente lo que los estudiantes producirán y cómo demuestra la competencia.

* Ejemplos: *Repositorio de código, plan de negocios, prototipo de diseño, informe de investigación, video pitch.*
* Los entregables deben estar **listos para portafolio** y ser **relevantes para el trabajo**.

---

## 7. Interacción Humana y Colaborativa

Integra oportunidades para mentoría, retroalimentación y aprendizaje comunitario.

* 🧑‍🏫 Sesiones de mentor / horas de oficina
* 👥 Desafíos grupales o revisiones entre pares
* 🌐 Foros o comunidades Slack/Discord
* 🎤 Presentaciones de proyectos y exhibiciones

---

## 8. Alinear con las Fases ADA

Asegúrate de que tu curso fluya a través de las **4 fases de aprendizaje ADA**:

1. **🙊 Introducción Autoguiada** → lecturas, videos, cuestionarios.
2. **🙉 Exploración Visual** → demostraciones, juego de roles, recorridos.
3. **🙈 Práctica Aplicada** → laboratorios, herramientas, simulaciones.
4. **🐵 Colaboración y Reflexión** → interacción entre pares, compartir proyectos.

---

## 9. Ejemplo de Flujo de Trabajo

1. **Competencia**: *Visualización de Datos con Python*.
2. **Objetivos**: *Comprender gráficos → Aplicar librerías → Crear dashboard.*
3. **Átomos**: *Introducción a matplotlib, Caso de estudio, Laboratorio sobre gráficos de barras.*
4. **Módulo**: *Fundamentos de Visualización de Datos.*
5. **Evaluación**: *Mini-rúbrica para laboratorios, dashboard capstone con rúbrica.*
6. **Entregable**: *Dashboard interactivo compartido en GitHub.*
7. **Interacción Humana**: *Retroalimentación entre pares sobre diseño de dashboard.*
8. **Fases**: *Concepto (Autoestudio) → Demo (Visual) → Laboratorio (Práctica) → Exhibición entre Pares (Colaboración).*

## ✅ Lista de Verificación para Diseñadores

Usa esta lista de verificación para asegurar que tu micro-credencial esté alineada con ADA. Los ejemplos se incluyen en cursiva para mayor claridad.

* [ ] **Definió una competencia del mundo real**
  *Ejemplo: "Capacidad de diseñar un mapa de recorrido del cliente para marketing digital."*
* [ ] **Vinculado a marcos/estándares (SFIA, O\*NET, ESCO, OIT)**
  *Ejemplo: "ESCO: Especialista en Marketing – Diseño del Recorrido del Cliente."*
* [ ] **Redactó objetivos de aprendizaje alineados con Bloom**
  *Ejemplo: "Analizar el comportamiento del usuario usando métricas de embudo."*
* [ ] **Diseñó 4–8 átomos de aprendizaje**
  *Ejemplo: Átomos sobre personas de clientes, dashboards de analíticas, pruebas A/B.*
* [ ] **Ensamblió átomos en módulos**
  *Ejemplo: Módulo = "Fundamentos de Analíticas de Usuario" con 3 átomos + un laboratorio.*
* [ ] **Definió evaluaciones con rúbricas**
  *Ejemplo: Mini-rúbrica para laboratorio de analíticas; rúbrica capstone para estrategia de marketing final.*
* [ ] **Especificó entregables (listos para portafolio)**
  *Ejemplo: Un PDF de mapa de recorrido del cliente y un informe de marketing basado en datos.*
* [ ] **Planificó elementos humanos/colaborativos**
  *Ejemplo: P&R semanal con mentor y revisión entre pares de informes.*
* [ ] **Mapeó fases (Oír → Ver → Hacer → Compartir)**
  *Ejemplo: Lecturas de autoestudio → Videos de demostración → Laboratorio de analíticas → Exhibición entre pares.*
