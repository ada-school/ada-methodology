# 📊 Rubrics — Problem Solving

All rubrics for this micro-credential. Atom-level rubrics are **formative** (gate progress); the
**capstone-5** rubric is the **summative** Assessment Rubric. Abilities are scored **behaviorally
across ≥3 occasions**, never with a quiz.

> See the rubric philosophy in [`../../guides/curriculum-design-guide.md`](../../guides/curriculum-design-guide.md)
> and the standard rubric in [`../../templates/micro-credential-ada-template.md`](../../templates/micro-credential-ada-template.md).

---

## 1) `knowledge-mini` — for Knowledge atoms (Atoms 1–2)

Formative checks for understanding (used by the pop quizzes).

| Criterion | Pass (✓) | Not yet (✗) |
| --------- | -------- | ----------- |
| **Comprehension** | Explains the process / a bias in own words | Recites without understanding |
| **Application** | Spots symptom-vs-cause or a bias in a scenario | Cannot transfer to a new case |
| **Reflection** | Connects the idea to a real problem | No connection made |

Pass = all ✓. Retake allowed.

---

## 2) `skill` — for Skill atoms (Atoms 3–4)

| Criterion | Excellent (3) | Adequate (2) | Needs work (1) |
| --------- | ------------- | ------------ | -------------- |
| **Define & decompose (Atom 3)** | Sharp, measurable, solution-free statement; MECE tree | Mostly clear + a breakdown | Vague / hides a solution |
| **Root cause (Atom 4)** | Reaches actionable cause; tests it | Some digging + a test | Stops at symptom; assumes cause |
| **Bias awareness** | Seeks disconfirming evidence | Some | Confirmation-driven |

Pass = 2+ on each relevant row → **L2** for the targeted Skill.

---

## 3) `behavioral` — for the Abilities (Atom 5, capstone, across the course)

Scored by **observation across ≥3 occasions** (Atom 5 challenge + pair review, the capstone defense,
and general participation). The Ability is credited only if it shows up **consistently.**

| Ability | Looks like (✓) | Doesn't look like (✗) | Occasions |
| ------- | -------------- | --------------------- | --------- |
| **Persistence & ambiguity tolerance (`A-persistence`)** | Stays with hard/unclear problems; refines instead of forcing | Grabs a premature answer; quits when foggy | Atom 5, capstone, throughout |
| **Critical, curious thinking (`A-critical-curious`)** | Questions assumptions; asks why/what-if; welcomes challenge | Accepts the obvious; defends first instinct | Atom 5, capstone, throughout |

Credit at **L2** = observed ✓ in **at least 3 occasions** (the capstone alone is not enough).

## 4) `capstone-5` — summative Assessment Rubric (the badge gate)

The standard ADA 5-criteria / 4-band / 100-point rubric. Identical to the table in
[`capstone.md`](capstone.md):

| Criteria | Excellent (100–90%) | Competent (89–80%) | Developing (79–70%) | Initial (69% or less) | Weight |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Relevance (competency alignment)** | A real, well-scoped problem run through the full process to a defensible solution. | Relevant; process mostly complete. | Process partial or problem trivial. | Off-target or solution-jumped. | **20 pts** |
| **Application of skills** | Framing, root-cause analysis, and decision matrix all used correctly and naturally. | Most used correctly. | Several gaps. | Minimal/incorrect. | **25 pts** |
| **Problem-solving (depth & rigor)** | Tests the root cause; trade-offs explicit; reversible pilot. | Adequate rigor. | Shallow diagnosis / unsupported choice. | No real analysis. | **20 pts** |
| **Clarity & communication (defense)** | Clear, logical defense; handles challenge questions. | Generally clear. | Uneven. | Unclear/missing. | **15 pts** |
| **Collaboration & reflection** | Persistence + critical curiosity evident; insightful review + honest reflection. | Adequate. | Minimal. | Missing. | **20 pts** |
| **TOTAL** | | | | | **100 pts** |

## 🏅 Badge issuance — *Problem Solver*

Issued when **all** hold (mentor-verified — human-in-the-loop):

- [ ] **Knowledge:** Atoms 1–2 pop quizzes passed.
- [ ] **Skills:** Atom 3 (frame) + Atom 4 (root cause) performance tasks ≥ 2 each → **L2.**
- [ ] **Abilities:** `A-persistence` & `A-critical-curious` observed ✓ across **≥3 occasions.**
- [ ] **Capstone:** Assessment Rubric weighted score **≥ 70%** (≥ *Developing* on each criterion).
- [ ] **Collaboration:** defense delivered + peer review given + reflection submitted.

The badge writes these KSA components (with levels) into the learner's **skills map** —
see [`skills-map.md`](skills-map.md).
