# 🚀 Capstone — *Solve a Real Problem End-to-End*

The capstone is delivered as [Atom 6](atoms/atom-6-capstone-solve-a-real-problem.md). This file is the
**grading brief**: what learners submit, how it maps to KSA, and the defense format.

---

## 🎯 The brief

> Pick a **real, non-trivial problem** you can work on within the course window. Run the **full
> problem-solving process** and produce a sharp **problem statement**, a **root-cause analysis**, a set
> of **options with a decision matrix**, your **chosen solution with the trade-off named**, and a
> **pilot/implementation plan** with a success metric. Then **defend it** and peer-review a classmate.

The point is the **quality of the thinking** — define → diagnose → decide — not the size of the
problem.

---

## 📦 What to submit

- [ ] **Problem statement** — specific, measurable, neutral, solution-free, with success metric.
- [ ] **Root-cause analysis** — 5 Whys and/or fishbone + how you **tested** the suspected cause.
- [ ] **Options + decision matrix** — ≥5 options, weighted criteria, the choice, the **trade-off named.**
- [ ] **Pilot/implementation plan** — smallest reversible test + what "it worked" looks like.
- [ ] **A reflection** (6–8 sentences) — where you got stuck, an assumption discarded, a bias caught.
- [ ] **A peer review you gave** — the capstone rubric applied to a classmate, with useful feedback.

---

## 🎤 Showcase / defense structure (≈ 5 minutes)

1. **The problem** (1 min) — statement + why it matters.
2. **The diagnosis** (1–2 min) — root cause + how you know.
3. **The decision** (1–2 min) — options, matrix, choice, trade-off.
4. **Next & lessons** (30s) — pilot plan + one lesson.

> Expect **challenge questions** ("what if your root cause is wrong?") — answering with your reasoning
> is part of the grade (critical-curiosity, observed live).

## 🧬 How the capstone maps to KSA

| Capstone element | Evidences | Component |
| ---------------- | --------- | --------- |
| Process discipline + symptom/root-cause distinction | The problem-solving process | 🧠 K-process |
| Naming trade-offs; catching a bias in the reflection | Decisions & cognitive biases | 🧠 K-decisions-biases |
| Sharp, decomposed problem statement | Define & decompose | 🛠️ S-frame (L2) |
| 5 Whys / fishbone + a real test | Root cause analysis | 🛠️ S-root-cause (L2) |
| Options + weighted decision matrix + choice | Generate & choose solutions | 🛠️ S-solutions (L2) |
| Staying with the messy problem; refining vs. forcing | Persistence & ambiguity tolerance | 🌱 A-persistence (L2) |
| Questioning assumptions; handling challenge questions | Critical, curious thinking | 🌱 A-critical-curious (L2) |
| Defense + peer review + reflection | Collaboration & reflection | (capstone-5 collaboration) |

> The Abilities (`A-persistence`, `A-critical-curious`) are confirmed here as the **3rd observed
> occasion**, after Atom 5 and across the course.

## ✅ Grading

Atom-level checks (`knowledge-mini`, `skill`, `behavioral`) gate entry to the capstone, which is then
scored on the standard 5-criteria **Assessment Rubric** below (also in [`rubrics.md`](rubrics.md)).

## 📋 Assessment Rubric

Five criteria across four proficiency bands, weighted to **100 points**.

| Criteria | Excellent (100–90%) | Competent (89–80%) | Developing (79–70%) | Initial (69% or less) | Weight |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **Relevance (competency alignment)** | A real, well-scoped problem run through the full process to a defensible solution. | Relevant; process mostly complete. | Process partial or problem trivial. | Off-target or solution-jumped. | **20 pts** |
| **Application of skills** | Framing, root-cause analysis, and decision matrix all used correctly and naturally. | Most used correctly, minor gaps. | Several gaps (weak diagnosis, gut decision). | Minimal/incorrect application. | **25 pts** |
| **Problem-solving (depth & rigor)** | Tests the root cause; trade-offs explicit; reversible pilot; reasoning sound. | Adequate rigor. | Shallow diagnosis or unsupported choice. | No real analysis. | **20 pts** |
| **Clarity & communication (defense)** | Defense is clear and logical; handles challenge questions well. | Generally clear. | Uneven or hard to follow. | Unclear/missing. | **15 pts** |
| **Collaboration & reflection** | Persistence + critical curiosity evident; insightful peer review + honest reflection (bias caught). | Adequate review + reflection. | Minimal. | Missing. | **20 pts** |
| **TOTAL** | | | | | **100 pts** |

> **Pass for the badge:** atom-level checks ≥ 2 each (incl. the behavioral assessment), Assessment
> Rubric weighted score ≥ 70% (at least *Developing* on every criterion), and the peer review +
> reflection completed — **verified by a mentor/instructor** (human-in-the-loop). See
> [`skills-map.md`](skills-map.md) for what the badge unlocks.
